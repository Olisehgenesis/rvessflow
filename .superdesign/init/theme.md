# Theme

## Compact tokens

Light theme only in practice.

- background `#FAF9F6` warm off-white
- foreground `#0B0F14` charcoal
- card `#FFFFFF`
- primary `#D9FF38` electric lime, text on it `#0B0F14`
- secondary / muted `#F3F1EA`
- muted-foreground `#4E5560`
- accent lavender wash `color-mix(#A78BFA 18%, white)`, token `--lavender #A78BFA`
- border / input `#E7E2D8`
- ring `#0B0F14`
- destructive oklch red
- radius `0.9rem`
- font sans: Inter (`--font-inter`)
- font display / headings / amounts: Manrope (`--font-manrope`)
- product marks: saving lime plant, flow lavender bolt, expense lavender arrow, lock orange padlock, group blue people
